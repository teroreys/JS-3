11) Przepisz linie kody pod nimi wytłumaczenie jak działa ta ten fragment kodu
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");
Otwiera małe okienko (160x280px) z plikiem "obraz.html" w wyznaczonym miejscu ekranu i ukrywa menu.

- toolbar=no → ukrywa pasek narzędzi (wstecz, dalej)
- directories=no → ukrywa pasek zakładek i katalogów
- menubar=no → ukrywa menu przeglądarkki (Plik, Edycja)
- height=280 → ustawia wysokość okna na 280 pikseli
- width=160 → ustawia szerokość okna na 160 pikseli
- top=200 → ustawia odległość 200 pikseli od góry ekranu
- left=200 → ustawia odległość 200 pikseli od lewej krawędzi

12)Opisz następującą instrukcję window.close()
Funkcja wykonuje zamykanie okna.

Gdy chcesz wyświetlić instrukcję, która nie powinna się wykonywać a tylko wyświetlać masz dwie możliwości:

Pierwsza możliwość:
Znak < możesz wyświetlić jako &lsaquo; (lub bezpieczniej dla kodu HTML: &lt;).
Znak > możesz wyświetlić jako &rsaquo; (lub bezpieczniej dla kodu HTML: &gt;).

Druga możliwość:
Tekst możesz umieścić w znacznikach <xmp>...</xmp>, <pre>...</pre> lub <code>...</code>.
Wyjaśnienie: Znacznik <xmp> (lub nowocześniejsze połączenie <pre><code>) sprawia, że przeglądarka automatycznie traktuje całą zawartość jako zwykły tekst i wyświetla surowy kod zamiast go interpretować i wykonywać.

<!DOCTYPE html>
<html lang="pl">
 <head>
 <meta http-equiv="Content-Type" content="text/html; charset=utf-8">
 <meta http-equiv="Content-Script-Type" content="text/javascript">
 <title>Moja strona WWW</title>
 <script type="text/javascript">
 function onclickHandler()
 {
 alert('Akapit został kliknięty!');
 }
 </script>
 </head>
 <body>
 <p onclick="onclickHandler();">Kliknij ten akapit,
 a pojawi się okno dialogowe.</p>
 </body>
</html>
